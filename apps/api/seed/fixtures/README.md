# Fixtures do seed

Itens usados pelo `FakeCatalog` no seed de demonstração (`pnpm seed`). O seed não chama a API
externa.

As imagens `obra-*.png` foram geradas por script (gradientes senoidais) para este projeto e
são dedicadas ao domínio público (CC0). Os metadados em `items.json` são fictícios e apontam
para `example.invalid`.
